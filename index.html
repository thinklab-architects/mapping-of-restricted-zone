地段號對照地段名示範地圖

使用 Mapbox GL JS 載入來自政府資料開放平台的底圖與地段資料， 透過點擊或輸入地段號來查詢對應的地段名。

請先建立 config.js 並設定 MAPBOX_TOKEN 與 LAND_API_URL。

設定

將 config.example.js 複製為 config.js， 並填入 Mapbox Access Token、底圖 Style URL，以及政府資料開放平台的地段 GeoJSON API 連結。

查詢地段號

查詢會以屬性名稱 LAND_NUMBER_PROPERTY 比對。
